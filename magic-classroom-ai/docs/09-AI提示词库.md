# Magic Classroom AI — AI Prompt 库

> 用途：为课程策划、场景规划、JSON 生成、素材需求和 Codex 开发提供标准化 Prompt。
> 原则：Prompt 结果均视为草稿，必须通过 Schema 校验和人工审核。

## 1. 课程结构化 Prompt
```text
你是数字课程产品设计师。
请根据输入教材生成结构化课程方案。

输出目标：
1. 课程标题
2. 学习目标
3. 关键知识点
4. 章节结构
5. 推荐互动形式
6. 适合学生年龄/年级
7. 预计学习时长

约束：
- 不虚构教材中没有的核心事实。
- 不直接输出 UI 代码。
- 内容应适合课堂教学。
- 若信息不足，标记 needs_review。
```

## 2. Scene Planner Prompt
```text
你是互动课程场景规划器。
输入：课程知识点和教学目标。
输出：场景数组。

允许 scene.type：
intro, map-explore, timeline, reading, quiz, matching, summary, result

每个场景输出：
id, type, title, objective, contentSummary, interactions, estimatedMinutes

要求：
- 场景数量控制在 5~10 个。
- 每个知识点至少被一个场景覆盖。
- 不为了炫技增加无教学价值互动。
```

## 3. Course JSON Prompt
```text
你负责把经过审核的课程方案转换为 CourseConfig JSON。

必须：
- 严格遵守指定 JSON Schema。
- 只输出 JSON，不输出解释。
- 所有 ID 在课程内唯一。
- 不创建未定义 scene.type。
- 所有媒体先使用 asset placeholder，不编造真实 URL。
- schemaVersion 使用调用方给出的版本。
```

## 4. JSON Repair Prompt
```text
下面 JSON 未通过 Schema 校验。
请只修复校验错误，不改变课程教学含义。

输入：
- 原 JSON
- validation errors
- JSON Schema

只输出修复后的 JSON。
如果无法安全修复，输出：
{"status":"needs_review","reason":"..."}
```

## 5. 英国主题 Demo 场景文案 Prompt
```text
为中学生互动课程“Magic Journey · Explore Britain”生成简短场景文案。
风格：原创英伦奇幻探险，不引用具体影视角色、台词或受版权保护设定。
语言：中文为主，关键英国地名保留英文。
每段不超过 80 个中文字符。
```

## 6. 原创导师角色 Prompt
```text
设计一名原创的年轻魔法学院导师角色，用于教育科技互动课程。
要求：
- 英伦奇幻气质，但不能复刻任何已知影视、动漫或游戏角色。
- 友好、聪明、具有探索者气质。
- 手持原创造型魔法棒或探索工具。
- 适合作为透明背景全身角色素材。
- 服装、徽章、配色必须原创。
```

## 7. 背景图 Prompt
```text
生成原创英伦奇幻学院夜景，用于 16:9 教育互动网页背景。
元素：月夜、远处古典学院建筑、湖面、薄雾、温暖窗灯、星点。
构图：中央和右侧保留人物与地图 UI 空间，左侧保留标题可读区。
禁止出现任何具体影视作品名称、校徽、角色或可识别建筑复刻。
```

## 8. 地图素材 Prompt
```text
创建简洁的英国地图教育信息图，突出 England、Scotland、Wales、Northern Ireland。
要求：
- 易于转换为 SVG 或矢量风格。
- 地区边界清楚。
- 无复杂文字纹理。
- 适合作为网页 hover 交互底图。
```

## 9. Quiz 生成 Prompt
```text
根据给定知识点生成 3~5 道课堂互动题。
每题输出：
id, type, prompt, options, answer, explanation, difficulty

约束：
- 答案必须能从教材内容推导。
- 干扰项合理但不故意模糊。
- explanation 简短明确。
- 不使用超出学生年级的术语。
```

## 10. 阅读互动 Prompt
```text
根据输入材料生成一个阅读互动场景。
输出：
- 标题
- 120~300 字阅读正文
- 3~6 个关键词
- 2~4 道理解题
- 一个总结问题

不要改变原始材料的关键事实。
```

## 11. 时间轴 Prompt
```text
将输入历史/文化内容转换为时间轴节点。
每个节点包含：date, title, description, importance, assetSuggestion。
如果原文没有明确日期，不得自行编造精确日期；可使用时期描述并标记 uncertainDate=true。
```

## 12. 素材需求 Prompt
```text
根据课程场景规划输出素材需求清单。
每条包括：assetId, type, purpose, visualBrief, ratio, priority, licenseRequirement。

不得推荐直接抓取影视截图、商业插画或授权不明音乐。
```

## 13. 教师 Review Prompt
```text
请以教师审核视角检查 AI 课程草稿。
重点：
- 是否偏离教材
- 是否存在事实风险
- 是否过度游戏化
- 题目是否有歧义
- 场景是否重复
- 学习目标是否被覆盖

输出问题清单和修改建议，不直接发布课程。
```

## 14. Codex Scene01 开发 Prompt
```text
你正在开发 Magic Classroom AI 的 Scene01 开场动画。
先阅读：README、PRD、技术架构、UI 规范、数据结构规范。

目标：完成可演示的 intro 模板，而不是把英国课程写死在组件中。
必须读取 SceneConfig 数据。

要求：
- React + TypeScript。
- Framer Motion 实现主要动画。
- 支持 reduced motion。
- 目录、声音、全屏可用。
- Start Journey 触发统一 CoursePlayer 导航。
- 素材缺失时有 fallback。
- 不使用未授权影视素材。
- 运行 lint/typecheck/build。

完成后汇报修改文件、测试结果和剩余问题。
```

## 15. Codex Debug Prompt
```text
请只修复下面问题，不进行无关重构。

输入：
- 复现步骤
- 期望结果
- 实际结果
- 控制台/构建错误

流程：
1. 找根因。
2. 修改最小范围代码。
3. 添加或更新测试。
4. 运行相关检查。
5. 说明根因和修复范围。
```

## 16. Codex Code Review Prompt
```text
审查当前变更是否符合 Magic Classroom AI 文档规范。
重点检查：
- 是否课程内容硬编码
- 类型安全
- a11y
- 性能
- 资源降级
- 密钥泄露
- 不必要依赖
- 测试缺失

按 blocker / major / minor 输出，不要为了风格偏好制造问题。
```

## 17. Prompt 管理原则
正式系统每个生成 Prompt 应保存：
- promptId
- version
- purpose
- model/provider
- inputSchema
- outputSchema
- changelog

修改 Prompt 不覆盖历史版本，以便复现已生成课程。
