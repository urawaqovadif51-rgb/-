# 正式上线 Checklist

## 产品
- [ ] PRD 范围冻结。
- [ ] 所有 P0 功能完成。
- [ ] Demo 功能与正式功能边界已标记。
- [ ] 教师端、学生端、管理员端权限已确认。
- [ ] 发布/下线流程已验证。

## 前端
- [ ] Production build 成功。
- [ ] TypeScript、lint、test 通过。
- [ ] 404/500/资源失败有 fallback。
- [ ] PC/大屏/平板主要分辨率验证。
- [ ] reduced-motion 可用。
- [ ] 音频遵循浏览器 autoplay 限制。
- [ ] 没有 API Key 或秘密写入 bundle。

## 后端
- [ ] 认证授权完成。
- [ ] 参数校验完成。
- [ ] 限流策略完成。
- [ ] 关键 API 有错误码和日志。
- [ ] AI 调用有超时、重试、成本/配额保护。
- [ ] 上传接口校验大小、类型和权限。

## 数据库
- [ ] Migration 可重复执行。
- [ ] Production migration 已备份。
- [ ] 索引检查。
- [ ] 数据保留/删除策略明确。
- [ ] 定期自动备份开启。
- [ ] 恢复演练通过。

## 对象存储与 CDN
- [ ] Bucket 非必要文件不公开写入。
- [ ] 上传采用授权/签名机制。
- [ ] CDN 缓存策略设置。
- [ ] 大图/音频已压缩。
- [ ] CORS 配置正确。

## 安全
- [ ] Secret Manager/环境变量配置。
- [ ] HTTPS 强制。
- [ ] Cookie/Token 安全属性正确。
- [ ] CORS 白名单最小化。
- [ ] 依赖漏洞扫描。
- [ ] 管理员入口有强化权限。
- [ ] 日志不打印敏感 token/密码。

## 内容与版权
- [ ] 所有图片、音乐、字体、地图具备可用授权或原创来源。
- [ ] 未使用未经许可的影视角色、官方标志、音频。
- [ ] AI 生成内容经过教师/编辑审核。
- [ ] 课程事实内容经过核对。

## 可观测性
- [ ] 前端错误监控。
- [ ] 后端日志集中化。
- [ ] API 延迟与错误率监控。
- [ ] 数据库 CPU/连接数/慢查询监控。
- [ ] AI 请求量、耗时、失败率、成本监控。
- [ ] 告警联系人配置。

## 性能
- [ ] 首屏静态资源压缩。
- [ ] 图片 WebP/AVIF。
- [ ] 场景懒加载。
- [ ] CDN 开启。
- [ ] 数据库连接池设置。
- [ ] 压测至少覆盖预期峰值并留安全余量。

## 发布流程
- [ ] Staging 环境通过验收。
- [ ] 发布 commit/tag 明确。
- [ ] 数据库备份完成。
- [ ] 回滚方案可执行。
- [ ] 发布后 smoke test 完成。
- [ ] 关键课程链接人工验证。

## Demo 演示前额外检查
- [ ] 领导演示设备提前打开一次，确保静态资源已缓存。
- [ ] 浏览器缩放 100%。
- [ ] 全屏按钮工作。
- [ ] 音量合适且可静音。
- [ ] 网络异常时准备本地/离线备份版本。
- [ ] Start Journey 与前 2~3 个核心场景完整跑通。
