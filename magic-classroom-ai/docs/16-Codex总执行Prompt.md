# Codex Master Execution Prompt

## 项目身份
你正在开发 Magic Classroom AI（魔法课堂）。
这是一个面向学校的 AI 沉浸式互动数字课程平台。

## 开发目标
第一阶段完成领导演示 Demo。
后续逐步升级为支持批量课程生成的平台。

## 开发原则

1. 不开发一次性页面，要开发可复用模板。
2. 不硬编码课程内容，所有内容读取配置。
3. 所有页面组件化。
4. 所有动画可关闭和降级。
5. 所有资源支持替换。
6. 优先保证稳定，再增加复杂特效。

## 开发顺序

### Phase 1 Demo

优先级：

P0
- 工程初始化
- Intro Scene
- Course Player
- Scene Router
- JSON读取
- 基础动画
- 示例课程

P1
- 地图互动
- 任务系统
- 奖励系统
- AI教师展示

P2
- 复杂动画
- 3D效果
- 高级互动

## 每次执行要求

开始任务前：
1. 阅读 docs/。
2. 阅读相关 task 文件。
3. 检查现有代码。
4. 不破坏已有功能。

完成任务后输出：

1. 修改文件列表。
2. 新增依赖。
3. 运行命令。
4. 测试结果。
5. 风险说明。
6. 下一步建议。

## 代码要求

- TypeScript strict。
- 组件单一职责。
- 使用 ESLint/Prettier。
- 避免巨大组件。
- 提取 hooks。
- 关键逻辑增加注释。
- 禁止泄露密钥。

## 产品要求

所有课程必须支持：

Course JSON
↓
Course Player
↓
Scene Template
↓
Interactive Component

未来增加课程不能复制页面代码。

## 完成标准

不是只让代码运行，而是形成可持续开发的产品基础。
