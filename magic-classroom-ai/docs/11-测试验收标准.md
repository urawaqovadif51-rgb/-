# Magic Classroom AI — 测试与验收标准

## 1. 测试目标
保证 Demo 可稳定演示，同时为正式产品建立自动化测试基础。

## 2. Scene01 验收
- 1920×1080 布局完整。
- 1366×768 无遮挡核心操作。
- 标题、导师、地图、工具栏、Start Journey 全部可见。
- Start Journey 能正确进入 Scene02。
- 目录按钮可开关目录。
- 声音按钮可静音/恢复。
- 全屏按钮可正常工作或明确降级。
- reduced motion 时动画显著减少。
- 素材加载失败不白屏。
- 页面无持续严重 console error。

## 3. CoursePlayer 验收
- 可读取 CourseConfig。
- 未知 scene.type 显示 fallback。
- next/prev 不越界。
- currentScene 和 progress 正确。
- 刷新后可恢复 Demo 基础进度。
- 场景快速连点不会导致重复跳转。

## 4. 模板验收
### Map Explore
热点可点击、键盘可聚焦；选中后显示对应信息。

### Timeline
节点顺序正确，详情可切换。

### Reading
正文可读，问题区独立，答题反馈明确。

### Quiz
正确/错误逻辑、解释、重试策略符合配置。

### Matching
有鼠标和非拖拽替代交互。

### Summary/Result
进度、分数、奖励展示正确。

## 5. 浏览器
Demo 至少验证：
- Chrome 最新稳定版。
- Edge 最新稳定版。

正式版再扩 Safari/Firefox。

## 6. 性能
- 首场景优先加载关键资源。
- 不因装饰动画产生持续严重卡顿。
- 避免同步加载整门课所有高清媒体。
- 低性能/减少动画模式可降级粒子等特效。

## 7. 可访问性
- Tab 可访问主要按钮。
- focus 状态可见。
- Icon Button 有 accessible name。
- 关键反馈不能只依靠颜色或声音。
- 文本对比度可读。

## 8. API 测试
正式 MVP：
- 鉴权。
- 权限隔离。
- 课程 CRUD。
- 发布版本。
- 上传签名。
- AI Job 状态。
- tenant 越权访问必须失败。

## 9. 安全测试
- 仓库无真实 secret。
- 上传类型/大小校验。
- 富文本 XSS 检查。
- 登录和 AI 生成限流。
- 后端不信任前端传入角色。

## 10. CI Gate
PR 必须通过适用项目：
- lint
- typecheck
- unit test
- build

## 11. Demo 演示前检查清单
- [ ] 演示 URL 可访问
- [ ] 首屏素材已加载或缓存
- [ ] 音量合适
- [ ] 全屏可用
- [ ] 所有场景可顺序进入
- [ ] 浏览器控制台无阻塞错误
- [ ] 网络断续时不会立刻白屏
- [ ] 准备一份离线/本地备用版本

## 12. 正式上线 Gate
只有以下条件全部满足才允许生产发布：
- 数据库备份已验证。
- HTTPS 正常。
- 监控告警启用。
- 秘密不在仓库。
- tenant 权限测试通过。
- 关键 E2E 通过。
- 可回滚版本存在。
