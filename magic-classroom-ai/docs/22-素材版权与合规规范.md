# 22. 素材版权与合规规范

## 1. 目标
确保课程背景图、角色、地图、音乐、音效、字体、图标和视频素材可用于学校演示及后续商业化，不因 Demo 阶段的临时素材形成产品化风险。

## 2. 素材来源分类
允许优先级：
1. 自研原创素材。
2. 明确获得商业授权的素材。
3. 许可条款允许商业使用、修改和再分发到本产品的开放素材。
4. AI 生成且通过内部审核、无明显第三方品牌/角色复刻的素材。

禁止：
- 直接复制影视、游戏、动漫中的具体角色、场景、UI 或官方海报。
- 直接使用来源不明的网络图片/音乐。
- 将只能个人使用或禁止商业使用的素材用于正式产品。
- 把第三方 Logo、商标当作平台自有品牌元素。

## 3. 项目视觉风格
可采用“原创英伦奇幻学院、深蓝+金色、古典校园、星空、魔法粒子”等抽象风格描述，但不得要求或制作对具体受保护影视作品的一比一复刻。

## 4. 素材台账
每个 Asset 至少记录：
- asset_id
- filename
- source_type
- source_url/供应商（如适用）
- license
- author/vendor
- commercial_use_allowed
- attribution_required
- generated_by_ai
- prompt/model（如内部需要）
- uploaded_by
- created_at
- review_status

## 5. AI 素材审核
AI 生成后检查：
- 是否出现明显知名角色、商标、电影服装/徽章等。
- 是否带不可识别水印。
- 是否包含不适合校园场景的内容。
- 是否与课程目标一致。

## 6. 字体
正式上线优先使用明确允许 Web 嵌入/商用的字体，记录许可证。不得把未知来源字体文件直接提交公开仓库。

## 7. 音乐与音效
必须确认商用及网络传播授权。Demo 若无法确认授权，使用自制/明确可商用素材或不放 BGM。

## 8. 学生与隐私
- 非必要不收集学生真实姓名、头像、联系方式。
- 学习分析尽量使用内部用户 ID。
- 公开展示页不得暴露学生个人记录。
- 未成年人数据的正式上线方案需由学校/法务结合实际部署地区要求审核。

## 9. 发布前检查
任何新课程发布前，素材必须有来源/授权状态；状态不明确的素材不得进入 Production。
