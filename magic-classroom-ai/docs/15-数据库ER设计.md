# Magic Classroom AI 数据库 ER 设计

## 设计目标

数据库用于支撑课程管理、AI生成流程、素材管理、学习记录和多学校扩展。

正式版本采用 PostgreSQL。

## 核心实体

## User
用户表

字段：
- id
- school_id
- role
- name
- email
- password_hash
- status
- created_at
- updated_at

角色：
- student
- teacher
- admin
- platform_admin

---

## School/Tenant
学校租户表

字段：
- id
- name
- domain
- plan
- status
- created_at

---

## Course
课程表

字段：
- id
- school_id
- title
- description
- cover_asset_id
- version
- status
- created_by
- created_at

状态：
- draft
- review
- published
- archived

---

## CourseVersion
课程版本

字段：
- id
- course_id
- version_number
- config_json
- created_by
- created_at

说明：
课程配置必须版本化，方便回滚。

---

## Scene
场景表

字段：
- id
- course_version_id
- type
- order_index
- config_json

类型：
- intro
- map-explore
- timeline
- reading
- quiz
- matching
- summary
- result

---

## Asset
素材表

字段：
- id
- type
- url
- size
- hash
- metadata_json
- created_at

类型：
- image
- audio
- video
- svg
- animation

---

## Template
模板表

字段：
- id
- name
- type
- schema_json
- version

---

## GenerationJob

字段：
- id

- prompt_version
- model

- status

状态：

---

## LearningSession

- id

---

## Reward

---

## 关系

School 1:N User

School 1:N Course

Course 1:N CourseVersion

CourseVersion 1:N Scene

CourseVersion N:M Asset

Template 1:N Scene

User 1:N GenerationJob

User 1:N LearningSession

LearningSession 1:N InteractionRecord

## 数据原则

1. 课程内容与代码分离。
2. JSON配置支持版本控制。
3. 素材不直接存数据库。
4. AI生成结果必须保存历史。
5. 所有重要操作记录审计日志。
