# Magic Classroom AI — UI / UX 设计规范

## 1. 设计目标
产品视觉应体现沉浸式、探索感、教育感和游戏化，但不能直接复制特定受版权保护影视作品的角色、校徽、场景或音乐。建议采用“原创魔法学院 + 英伦探险”方向。

## 2. 设计原则
1. 教学内容优先于装饰。
2. 主操作必须清晰。
3. 动画服务于引导，不干扰阅读。
4. 大屏优先，兼容笔记本和平板。
5. 课程模板风格统一，但允许主题换肤。

## 3. 视觉基调
推荐基础主题：
- 深夜蓝 / 靛青：背景
- 暖金色：主强调
- 米白：正文
- 青蓝：互动热点
- 紫色：魔法特效辅助

不要将所有文本都使用发光效果；正文应保持高可读性。

## 4. Design Tokens
建议使用 CSS Variables：
```css
:root {
  --mc-bg: #0d1326;
  --mc-surface: rgba(18, 28, 51, .78);
  --mc-text: #f7f3e8;
  --mc-text-muted: #c5c7d2;
  --mc-accent: #d9b25f;
  --mc-focus: #86b8ff;
  --mc-danger: #ef6b6b;
  --mc-radius-md: 16px;
  --mc-radius-lg: 24px;
}
```
实际实现可微调，但必须集中管理。

## 5. 字体
- 中文正文优先系统无衬线字体，确保学校电脑无需额外字体文件。
- 英文大标题可使用具有古典/奇幻气质且许可证明确的 Web Font。
- 正文字号大屏建议不低于 18px。
- 重要按钮建议 18~22px。

## 6. 网格与安全区
核心画布以 16:9 设计，1920×1080 为主要参考。
- 左右安全边距：64~96px。
- 顶部安全区：48~72px。
- 底部关键操作避免贴底。
- 1366×768 时按比例压缩但保证主要按钮可见。

## 7. 按钮
### Primary
用于 Start Journey、下一步、提交答案。
- 明确金色/主题强调。
- Hover 可增加 glow 和轻微 scale。
- Active 不超过 0.98 scale。
- Focus 必须有可见 outline。

### Secondary
目录、返回、辅助操作，视觉弱于主按钮。

### Icon Button
最小点击区域 44×44px；必须有 `aria-label` 和 tooltip。

## 8. 卡片
MagicCard 统一：半透明表面、柔和边框、轻微背景模糊；不要过度使用厚重拟物纹理影响性能。

## 9. Scene01 视觉规范
布局建议：
- 左侧 32%：标题与课程介绍。
- 中部 36%：原创导师。
- 右侧 32%：地图和工具栏。

层级：
1. 背景天空/城堡或英伦奇幻建筑。
2. 雾/光/星点。
3. UI 与地图。
4. 人物。
5. 主按钮和工具栏。

Start Journey 应成为全页最明显交互点。

## 10. 动画规范
### 时长
- 微交互：120~220ms
- UI 入场：300~600ms
- 场景转场：450~900ms
- 装饰循环：4~20s

### Easing
优先 ease-out / spring，不让文字持续晃动。

### reduced motion
当系统开启减少动态效果：
- 移除视差。
- 停止粒子连续运动或显著减少。
- 入场改为简单 opacity。

## 11. 地图
英国地图使用可授权 SVG 或自行绘制简化地图。
- 地区 hover 高亮。
- 热点尺寸足够大。
- 不只依赖颜色传递状态。
- 选中节点显示名称/卡片。

## 12. AI 导师
角色应原创，不使用知名影视人物作为产品正式资产。
角色系统支持：
- avatar
- name
- pose
- theme
- speech
- animationPreset

第一版仅需透明 PNG/WebP + CSS/Framer Motion 呼吸动画即可。

## 13. 音频 UX
- 默认显示声音开关。
- 未经用户交互不强制播放。
- BGM 音量低于语音/反馈音效。
- 用户静音后跨场景保持。

## 14. 教师端
教师端不需要魔法特效堆叠，重点是效率：
- 左侧导航。
- 内容区。
- 场景编辑器三栏结构。
- 所有保存状态明确展示。

## 15. 响应式
### >=1440
完整三栏沉浸式布局。

### 1024~1439
适当缩小人物和地图，保持主按钮可见。

### 768~1023
可将介绍和地图叠层重排。

### <768
正式产品后续提供移动布局；Demo 不要求完整复刻桌面构图。

## 16. 可访问性
- 文字与背景达到合理对比度。
- 键盘导航顺序符合视觉顺序。
- 所有交互元素有 focus 状态。
- 装饰图片 `alt=""`，信息图片提供 alt。
- 不能只通过音效表示答题结果。

## 17. 素材规范
- 背景：WebP/AVIF。
- 人物透明素材：WebP/PNG。
- 图标、地图：SVG。
- 不把 4K 原图直接塞入页面。
- 素材应记录来源、授权和生成方式。

## 18. 禁止事项
- 正文大量霓虹发光。
- 所有元素同时运动。
- 自动播放高音量音乐。
- 用未授权影视截图/人物/音乐作为正式产品素材。
- 在移动端强行缩小整个 1920 画布导致文字不可读。
