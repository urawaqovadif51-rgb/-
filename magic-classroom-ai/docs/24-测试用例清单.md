# 24. 测试用例清单

> 用于 Demo、MVP 和后续产品化验收。自动化与人工测试均可按编号执行。

## A. Scene 01 开场动画
- TC-S01-001：首次打开页面能正常渲染，不白屏。
- TC-S01-002：1920×1080 下标题、导师、地图、CTA 均完整可见。
- TC-S01-003：1366×768 下无关键元素遮挡。
- TC-S01-004：Start Journey 能进入 Scene 02。
- TC-S01-005：声音按钮能切换 muted/unmuted。
- TC-S01-006：浏览器禁止 autoplay 时页面仍可正常使用。
- TC-S01-007：全屏按钮进入全屏，再次操作退出。
- TC-S01-008：不支持 Fullscreen API 时优雅降级。
- TC-S01-009：背景资源加载失败时显示 CSS fallback。
- TC-S01-010：导师素材失败时显示占位视觉。
- TC-S01-011：地图失败时显示文本区域列表。
- TC-S01-012：prefers-reduced-motion 下关闭持续复杂动画。
- TC-S01-013：Tab 可聚焦主要控制，Enter/Space 可激活 CTA。
- TC-S01-014：配置中修改标题无需改代码即可生效。
- TC-S01-015：配置中替换背景路径无需改组件即可生效。

## B. Course Player
- TC-PLY-001：根据 scene.type 正确选择模板。
- TC-PLY-002：未知 scene.type 显示 fallback，而非崩溃。
- TC-PLY-003：next/previous 边界正确。
- TC-PLY-004：刷新后可恢复本地 Demo 进度。
- TC-PLY-005：正式模式可从 API 读取发布课程。
- TC-PLY-006：场景资源按需加载。
- TC-PLY-007：完成最后场景后进入 Result。

## C. Map Scene
- TC-MAP-001：热点按 JSON 坐标显示。
- TC-MAP-002：热点 hover/focus 可见。
- TC-MAP-003：点击热点出现对应内容。
- TC-MAP-004：键盘用户可访问热点。
- TC-MAP-005：热点配置为空时有空状态。

## D. Timeline Scene
- TC-TIME-001：按配置顺序展示时间节点。
- TC-TIME-002：节点内容可展开/切换。
- TC-TIME-003：小屏下可横向或纵向正常浏览。
- TC-TIME-004：无图片时布局不破坏。

## E. Reading / Quiz / Matching
- TC-Q-001：单选题选择答案后可提交。
- TC-Q-002：正确答案产生预期分数。
- TC-Q-003：重复提交不会重复加分。
- TC-Q-004：错误答案反馈清晰但不暴露不必要敏感信息。
- TC-Q-005：Matching 全部正确后进入完成态。
- TC-Q-006：刷新后的答案状态按产品规则处理。

## F. Auth & Permission
- TC-AUTH-001：正确账号可登录。
- TC-AUTH-002：错误密码返回 401。
- TC-AUTH-003：Student 无法调用教师课程写接口。
- TC-AUTH-004：Teacher 无法修改其他租户课程。
- TC-AUTH-005：过期 token 被拒绝。
- TC-AUTH-006：前端隐藏按钮不是唯一权限保护，后端必须拒绝越权。

## G. Course Authoring
- TC-CRT-001：教师创建空课程草稿。
- TC-CRT-002：新增 Scene。
- TC-CRT-003：调整 Scene 顺序。
- TC-CRT-004：替换素材。
- TC-CRT-005：预览草稿。
- TC-CRT-006：发布指定版本。
- TC-CRT-007：发布后 Public Player 读取的是已发布版本。
- TC-CRT-008：复制课程形成独立草稿。

## H. Asset
- TC-AST-001：允许格式可上传。
- TC-AST-002：超出大小限制被拒绝。
- TC-AST-003：伪造扩展名/MIME 被拒绝。
- TC-AST-004：被课程引用素材删除时返回冲突或执行安全规则。
- TC-AST-005：私有素材不可通过未授权公开 URL 获取。

## I. AI Generation
- TC-AI-001：创建 Job 返回 202。
- TC-AI-002：Job 状态按流程推进。
- TC-AI-003：无效模型输出经过 Schema 校验后进入 retry/fail。
- TC-AI-004：失败任务可 retry。
- TC-AI-005：AI 结果默认作为草稿，不自动发布。
- TC-AI-006：生成课程中的 scene.type 必须存在于模板 registry。
- TC-AI-007：生成结果可追踪 model/prompt/schema version。
- TC-AI-008：高风险或不适合课堂的内容进入审核/阻断流程。

## J. API
- TC-API-001：列表分页正确。
- TC-API-002：400/401/403/404/409/422/429/500 使用统一错误结构。
- TC-API-003：Idempotency-Key 防止关键操作重复创建。
- TC-API-004：公开课程接口不泄露教师备注、内部 AI 字段、私有存储信息。
- TC-API-005：OpenAPI 与实际路由一致。

## K. Database
- TC-DB-001：Alembic upgrade 全新库成功。
- TC-DB-002：核心 migration downgrade 在测试环境成功。
- TC-DB-003：多租户查询不会串校数据。
- TC-DB-004：必要唯一约束生效。
- TC-DB-005：软删除对象不出现在默认查询。

## L. Performance
- TC-PERF-001：首屏不一次下载全部课程素材。
- TC-PERF-002：动画主要使用 transform/opacity。
- TC-PERF-003：低性能设备可关闭/降低粒子。
- TC-PERF-004：图片使用合理尺寸和压缩格式。
- TC-PERF-005：持续交互无明显内存增长。

## M. Accessibility
- TC-A11Y-001：主要流程仅键盘可完成。
- TC-A11Y-002：图标按钮有可访问名称。
- TC-A11Y-003：焦点状态可见。
- TC-A11Y-004：文本与背景对比度可读。
- TC-A11Y-005：reduced motion 生效。

## N. Security
- TC-SEC-001：仓库无真实 API Key、DB 密码、JWT secret。
- TC-SEC-002：上传接口限制文件类型和大小。
- TC-SEC-003：日志不记录明文密码/token。
- TC-SEC-004：CORS 生产配置不使用无条件 `*`。
- TC-SEC-005：关键写接口有 CSRF/认证策略对应设计。
- TC-SEC-006：依赖扫描无已知严重漏洞或有明确处置记录。

## O. Leadership Demo Smoke Test
演示前必须通过：
1. 打开首页。
2. Scene01 动画完整。
3. 点击 Start。
4. 地图互动成功。
5. 时间轴/阅读至少一个互动成功。
6. AI 导师 Demo 流程成功。
7. 结果页展示。
8. 刷新/返回不会导致白屏。
9. 音频和全屏可控。
10. 备用网络/本地部署方案已准备。

## 自动化优先级
P0 自动化：build、typecheck、JSON schema、API auth/permission、CoursePlayer、发布流程。
P1 自动化：Scene 组件、AI job、asset upload、a11y smoke。
P2：视觉回归、跨浏览器和性能基准。
