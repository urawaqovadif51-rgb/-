# Magic Classroom AI — 数据结构规范

## 1. 目标
课程内容必须与页面代码分离。课程、场景、交互、素材和奖励通过 JSON/数据库数据驱动，便于批量生产、AI 生成、版本管理和模板复用。

## 2. CourseConfig
```json
{
  "schemaVersion": "1.0",
  "courseId": "magic-journey-britain",
  "version": 1,
  "title": "Magic Journey",
  "subtitle": "Explore Britain",
  "language": "zh-CN",
  "theme": "magic-britain",
  "teacher": {
    "id": "teacher-mage-01",
    "name": "Avery",
    "avatar": "/assets/teachers/avery.webp"
  },
  "audio": {
    "bgm": "/assets/audio/britain-theme.mp3",
    "defaultMuted": true,
    "volume": 0.25
  },
  "scenes": []
}
```

## 3. SceneConfig
```json
{
  "id": "scene-01",
  "type": "intro",
  "title": "Magic Journey",
  "order": 1,
  "required": true,
  "background": {
    "image": "/assets/backgrounds/britain-night.webp"
  },
  "content": {},
  "interactions": [],
  "rewards": []
}
```

## 4. Scene 类型
首批标准类型：
- intro
- map-explore
- timeline
- reading
- quiz
- matching
- summary
- result

禁止用 `scene01`, `pageA` 这类与模板能力无关的 type。

## 6. Interaction
统一基础字段：
```json
{
  "id": "quiz-01",
  "type": "single-choice",
  "prompt": "Which city is the capital of the UK?",
  "options": [
    {"id": "a", "text": "London"},
    {"id": "b", "text": "Manchester"}
  ],
  "answer": {"optionId": "a"},
  "feedback": {
    "correct": "Correct!",
    "incorrect": "Try again."
  }
}
```

正式环境如需防止答案直接暴露在客户端，可将判分逻辑放服务端；Demo 可先前端完成。

## 8. Asset
```json
{
  "id": "asset-001",
  "type": "image",
  "url": "https://cdn.example.com/...",
  "mimeType": "image/webp",
  "width": 1920,
  "height": 1080,
  "sizeBytes": 345678,
  "license": "owned-or-generated",
  "source": "internal"
}
```

素材必须保留授权/来源元数据，正式产品避免使用授权不明素材。

## 12. InteractionRecord
记录最少必要信息：
- sessionId
- sceneId
- interactionId
- eventType
- result
- scoreDelta
- timestamp

不要无目的采集大量行为数据。

## 13. 数据库建议
核心表：
- users
- tenants
- memberships
- courses
- course_versions
- templates
- assets
- generation_jobs
- learning_sessions
- interaction_records
- audit_logs

## 14. 版本规则
- `schemaVersion`：数据结构大版本。
- `CourseVersion.version`：课程内容版本。
- 已发布版本不可原地覆盖。
- 新发布生成新版本。
- 播放器需知道如何处理旧 schema，或拒绝并显示升级提示。

## 15. JSON Schema 校验
AI 生成结果和教师保存场景前均应经过 Schema 校验。

至少检查：
- 必填字段。
- scene type 是否支持。
- ID 是否唯一。
- 场景 order 是否有效。
- 引用 Asset 是否存在。
- interaction 数据是否合法。

## 16. 批量生成原则
第二门、第三门课程只新增 CourseConfig/素材，不创建新的 React Page。只有出现新的教学交互模型时才增加模板类型。
