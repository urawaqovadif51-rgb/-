# Magic Classroom AI — 组件设计规范

## 1. 目标
建立可复用、配置驱动、可测试的组件体系。课程模板只组合组件，不重复实现基础 UI。

## 2. 基础组件
### MagicButton
Props：variant、size、disabled、loading、icon、onClick。
要求：键盘可操作、focus 可见、支持 reduced motion。

### MagicCard
Props：title、subtitle、interactive、padding、children。
用途：信息卡、知识卡、地图说明。

### IconButton
必须提供 aria-label；点击区域至少 44×44。

### Modal / Drawer
用于目录、帮助、设置。支持 Esc 关闭和焦点管理。

### ProgressBar
显示课程进度；支持百分比和场景数。

### Tooltip
图标按钮和地图热点可用。

## 3. 课程引擎组件
### CoursePlayer
职责：加载配置、管理场景、导航、进度和异常。

### SceneRenderer
根据 scene.type 从 Scene Registry 渲染模板。

### SceneTransition
统一转场，避免每个模板重复实现。

### CourseToolbar
目录、声音、全屏、返回等公共操作。

## 4. Intro 组件
### MagicBackground
背景图、渐变、雾、星点和降级策略。

### CourseTitle
标题、副标题、描述入场。

### TeacherAvatar
原创导师角色展示；角色资源配置化。

### BritainMap
只承担地图视觉和地区交互，数据从 props 读取。

### StartJourneyButton
主 CTA；完成后调用 CoursePlayer 导航，不直接写路由字符串。

### ParticleLayer
纯装饰，pointer-events:none；支持关闭/降级。

## 5. Map Explore
### InteractiveMap
Props：asset、regions、hotspots、selectedId、onSelect。

### MapHotspot
支持 pointer 和 keyboard。

### RegionInfoCard
展示名称、图文、完成状态。

## 6. Timeline
### TimelineTrack
管理节点布局。

### TimelineNode
日期、标题、状态。

### TimelineDetail
节点详细内容。

## 7. Reading
### ReadingArticle
正文展示。

### KeywordChip
关键词释义。

### ReadingQuestion
复用 Quiz 交互，不单独写判分逻辑。

## 8. Quiz
### QuizShell
题目公共布局。

### ChoiceQuestion
单选/多选。

### FeedbackPanel
正确/错误/解释。

## 9. Reward
### RewardBadge
徽章展示。

### CoinCounter
金币动画和数量。

奖励数据由引擎计算，展示组件不负责业务规则。

## 10. Audio
### AudioManager
全局音频状态与播放控制。

### SoundToggle
只负责 UI。

### SfxPlayer
反馈音效，必须遵守用户静音状态。

## 11. 组件 API 原则
- Props 尽量小而明确。
- 不传整个全局 store 给纯展示组件。
- 不在基础组件中读取具体课程 ID。
- 业务事件使用回调注入。
- 可复用组件不依赖具体 scene type。

## 12. 错误与加载
所有关键资源组件支持：loading、error、fallback。

例如地图 SVG 加载失败时显示简化占位，不让场景白屏。

## 13. 样式原则
- Design Token 集中定义。
- 不在组件中大量写任意 hex。
- z-index 使用统一层级表。
- 动画参数使用 presets。

## 14. 测试要求
基础组件至少验证：
- 正常渲染
- disabled/loading
- keyboard interaction
- callback
- accessibility name

核心模板增加场景级测试。

## 15. 命名
- 组件 PascalCase。
- Hook 以 use 开头。
- Scene 模板统一 `XxxScene`。
- 配置类型统一 `XxxConfig`。
- 运行时结果统一 `XxxResult`。
