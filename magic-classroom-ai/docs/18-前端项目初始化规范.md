# 18. 前端项目初始化规范

## 1. 技术栈
- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Framer Motion
- Zustand
- Zod

## 2. 目录建议
```text
src/
├── app/
├── components/
├── features/
├── pages/
├── scenes/
├── hooks/
├── stores/
├── services/
├── schemas/
├── types/
├── utils/
└── assets/
```

## 3. 规则
- 课程内容从 JSON/API 读取。
- Scene 组件只负责渲染和交互，不直接耦合具体课程。
- 公共 UI 组件放 components；业务模块放 features。
- 页面路由放 pages；场景模板放 scenes。
- API 调用集中 services。
- 类型优先从 OpenAPI/Schema 生成或共享。

## 4. 状态管理
全局只保存跨场景必要状态：用户、当前课程、当前场景、声音、进度、奖励。
局部动画/UI 状态留在组件内，避免全局 store 膨胀。

## 5. 路由建议
- `/` 产品入口
- `/demo/:slug` 公开 Demo
- `/course/:slug/play` 学生播放器
- `/teacher/courses` 教师课程
- `/teacher/courses/:id/edit` 编辑器
- `/admin` 管理端

## 6. 质量门槛
每次 Codex 任务完成至少运行：
```bash
npm run lint
npm run typecheck
npm run test
npm run build
```
若暂未配置某命令，先补基础配置或明确说明。

## 7. 环境变量
只有 `VITE_` 前缀变量可以进入浏览器，严禁放数据库密码、AI Secret Key、JWT 私钥等秘密。

## 8. 性能
- 场景懒加载。
- 图片 WebP/AVIF。
- 地图优先 SVG。
- 大动画组件按需加载。
- 不把所有课程素材打进主 bundle。

## 9. 错误处理
建立 ErrorBoundary、404 页面、课程加载失败页、资源 fallback 和请求错误提示。

## 10. 首个开发目标
第一阶段只要求播放器框架 + Scene01 + 最少 2 个后续模板跑通完整导航，避免先开发复杂后台。
